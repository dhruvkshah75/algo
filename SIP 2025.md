## 2. Magic Numbers Using Two Digits

You are given two digits `A` and `B`.

Alice likes a number if every digit in that number is either `A` or `B`.

Bob likes a number if every digit of the sum of digits of that number is either `A` or `B`.

If a number is liked by both Alice and Bob, it is called a **Magic Number**.

For example, let `A = 1` and `B = 3`.

Consider the number `12`.

- The sum of digits of `12` is `3`, so Bob likes it.
- Alice does not like it because digit `2` is neither `1` nor `3`.
- Therefore, `12` is not a Magic Number.

Consider the number `111`.

- The sum of digits of `111` is `3`, so Bob likes it.
- Alice also likes it because all digits are `1`.
- Therefore, `111` is a Magic Number.

Your task is to count the number of magic numbers of length `N`.

Since the answer can be very large, print it modulo `1,000,000,007`.

### Input Format

The first line contains three integers:

```text
A B N
```

### Constraints

```text
1 <= A < B <= 9
1 <= N <= 10^6
```

### Output Format

Print a single integer: the number of magic numbers of length `N` modulo `10^9 + 7`.

### Sample Input

```text
1 3 3
```

### Sample Output

```text
1
```

## 6. Average Lactation Period per Animal

You are given lactation dates for a group of animals.

For each animal, compute the average lactation period, where the lactation period is the number of days between two consecutive lactation dates of the same animal.

### Input Format

The first line contains an integer representing the number of `Animal_ID` entries.

The second line contains numerical strings representing the `Animal_ID` entries.

The third line contains an integer representing the number of lactation dates.

The fourth line contains the lactation dates in `YYYY-MM-DD` format.

The `i`th animal ID corresponds to the `i`th lactation date.

For every unique animal ID, at least two different lactation date records are provided.

### Output Format

Print a two-column table:

```text
Animal_ID Average_period
```

Do not print column names.

Rules:

- Each `Animal_ID` must appear only once.
- The number of output rows must equal the number of unique animal IDs.
- `Average_period` is the mean number of days between consecutive lactations, rounded to one decimal place.
- Sort the output by `Average_period` in descending order.
- If two animals have the same `Average_period`, sort them by `Animal_ID` in ascending order.

### Constraints

```text
The input contains no more than 250 rows.
```

### Sample Input

```text
5
2188734000014 2188734000014 2188734000016 2188734000016 2188734000016
5
2016-02-08 2016-06-10 2016-04-19 2016-05-12 2016-06-25
```

### Sample Output

```text
2188734000014    123.0
2188734000016    33.5
```

### Explanation

There are two unique animal IDs.

For animal `2188734000014`, the two dates differ by `123` days, so the average period is `123.0`.

For animal `2188734000016`, the three dates give two gaps:

```text
2016-04-19 to 2016-05-12 = 23 days
2016-05-12 to 2016-06-25 = 44 days
```

The average is:

```text
(23 + 44) / 2 = 33.5
```

Since `123.0 > 33.5`, animal `2188734000014` is printed first.

## 10. Balanced Numbers in a Permutation

```text
1 <= l <= r <= n
```

and the subarray:

```text
p[l], p[l + 1], ..., p[r]
```

```text
1, 2, ..., k
```

Return a binary string of length `n`, where the `k`th character is:

- `1` if `k` is balanced,
- `0` otherwise.

A permutation of length `n` contains every integer from `1` to `n` exactly once.

### Example

```text
n = 4
p = [4, 1, 3, 2]
```

For `k = 4`, choose `l = 1`, `r = 4`. The entire array is `[4, 1, 3, 2]`.

Therefore, the answer is:

```text
1011
```

### Function Description

Complete the function `countBalancedNumbers`.

### Parameter

```text
int p[n]: the given permutation
```

### Return Value

```text
string: the binary string described above
```

### Constraints

```text
1 <= n <= 2 * 10^5
1 <= p[i] <= n
All p[i] are distinct.
```

## 22. Count Good Numbers

A prime number is a positive integer that has exactly two divisors: `1` and itself.

The first several prime numbers are:

```text
2, 3, 5, 7, 11, ...
```

Prime factorization of a positive integer means representing it as a product of prime numbers.

For example:

```text
111 = 3 * 37
43 = 43
12 = 2 * 2 * 3
```

For every positive integer, its prime factorization is unique if the order of prime factors is ignored.

A positive integer is called **good** if all prime numbers in its factorization have at least two digits.

In other words, none of its prime factors may be one of:

```text
2, 3, 5, 7
```

Examples:

- `343 = 7 * 7 * 7` is not good.
- `111 = 3 * 37` is not good.
- `1111 = 11 * 101` is good.
- `43 = 43` is good.

You must calculate the number of good integers in the range `[l, r]`.

### Input Format

The first line contains an integer `t`, the number of test cases.

Each test case contains two integers:

```text
l r
```

### Constraints

```text
1 <= t <= 10^3
2 <= l <= r <= 10^18
```

### Output Format

For each test case, print one integer: the number of good integers from `l` to `r`, inclusive.

## 24. Mario's Adventure Across the River

## 26. Plates Connectivity with Distance Constraint

You are given `N` plates placed on a 2D grid. The `i`th plate is located at coordinate:

```text
(x[i], y[i])
```

Two plates are considered directly connected if either:

- they lie in the same row and the absolute difference of their `x`-coordinates is at most `d`, or
- they lie in the same column and the absolute difference of their `y`-coordinates is at most `d`.

Connectivity is transitive. That is, if plate `A` is connected to plate `B`, and plate `B` is connected to plate `C`, then all three plates belong to the same connected component.

Find the number of connected components among all plates.

Equivalently, if one operation can connect two components using a valid direct connection, this count can be used to determine the minimum number of groups that remain after all possible valid connections are made.

### Input Format

The input contains:

```text
N
d
x[0] y[0]
x[1] y[1]
...
x[N - 1] y[N - 1]
```

### Constraints

```text
1 <= N <= 100000
0 <= x[i], y[i] <= 10^9
0 <= d <= 10^9
```

### Output Format

Print a single integer: the number of connected components.

### Sample

```text
N = 4
d = 1
x = [0, 0, 1, 2]
y = [0, 1, 0, 2]
```

The plates are:

```text
(0, 0), (0, 1), (1, 0), (2, 2)
```

The first three plates are connected through row or column distance `1`. The plate `(2, 2)` is isolated.

So the number of connected components is:

```text
2
```
